# Bio Link Professional - V1 🚀

Este repositório contém o código-fonte original da primeira versão do meu agregador de links personalizado. O projeto foi concebido para substituir ferramentas de terceiros, oferecendo maior controle sobre o branding e a experiência do usuário.

## 📈 Evolução do Projeto
Atualmente, este projeto evoluiu para uma solução profissional em ambiente de produção. Você pode conferir a versão atualizada e hospedada em domínio próprio aqui:
👉 **[dsxsublimacao.com.br/bio.html](https://dsxsublimacao.com.br/bio.html)**

## 🛠️ Tecnologias e Conceitos Aplicados
- **HTML5 Semântico**: Estruturação focada em acessibilidade e SEO.
- **CSS3 Personalizado**: Design responsivo (mobile-first) com botões interativos e efeitos de hover.
- **JavaScript**: Implementação de lógica de redirecionamento dinâmico e integração com APIs de redes sociais (WhatsApp/Instagram).
- **Branding**: Aplicação de identidade visual voltada para conversão de negócios.

## 🎯 Objetivo do Repositório
Este código serve como um registro de evolução técnica e prova de conceito (PoC) para:
1. Desenvolvimento de interfaces limpas e objetivas.
2. Integração de múltiplos pontos de contato (Redes Sociais, WhatsApp e Portfólio).
3. Gestão de presença digital para marcas e profissionais.
