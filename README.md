# Bio Link Personalizado 🚀

Um agregador de links profissional e minimalista, desenvolvido para centralizar a presença digital em redes sociais.

Este projeto foi criado como uma alternativa personalizada às ferramentas de mercado (como Linktree), permitindo total controle sobre o design, rastreamento e branding.

## 🛠️ Tecnologias
- **HTML5 Semântico**: Utilização de tags como `<header>`, `<main>` e `<footer>`.
- **CSS3**: Estilização de botões interativos e layout centralizado.
- **JavaScript**: Funções de redirecionamento dinâmico.

## 🌟 Diferenciais
- Botões interativos com ícones personalizados.
- Call to Action (CTA) direto para WhatsApp.
- Leve e otimizado para dispositivos móveis.
